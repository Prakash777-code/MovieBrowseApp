# MovieVerse 🎬

A simple Android app to search movies and view details using the OMDb API.

---

## 🚀 Features
- 🔍 Search movies by title
- 📃 View list of results
- 🎬 Movie detail screen
- ⚡ Fast API integration
- 🔄 Handles rotation using ViewModel
- ❌ Proper error handling (invalid search, network issues)
